# 🎬 MovieIQ — Predictive Analytics on Film Success

An interactive Streamlit dashboard that explores and predicts whether a movie will be a
financial success — defined as **revenue > budget** — using data cleaning, EDA,
statistical testing, and a Random Forest classifier.

## How to Run Locally

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. (Re-)generate the model and charts (optional — already included)
The `assets/` and `model/` folders are already populated, but if you want to
regenerate everything from scratch:
```bash
python train_analysis.py
```
This will re-clean the data, re-run the EDA and statistical tests, retrain the
Random Forest model, and overwrite the files in `assets/` and `model/`.

### 3. Launch the Streamlit app
```bash
streamlit run MovieIQ.py
```
Your browser should open automatically at `http://localhost:8501`. If it
doesn't, open that URL manually.

## App Features

- **Sidebar filters** — filter the entire dashboard by genre and minimum vote average.
- **Overview tab** — key metrics, success/failure split, top genres, data sample.
- **Exploratory Analysis tab** — budget vs revenue, genre trends, feature-vs-success
  box plots, correlation heatmap (all recomputed live on the filtered data).
- **Statistical Tests tab** — live t-test (vote_average vs success) and chi-square
  test (genre vs success), with plain-language explanations.
- **Model Performance tab** — accuracy/precision/recall, confusion matrix, and
  feature importance for the trained Random Forest.
- **Predict Success tab** — enter a hypothetical movie's budget, popularity,
  runtime, vote average, and genre to get a live success/failure prediction with
  a confidence score.

## Deploying to Streamlit Community Cloud (optional)

1. Push this folder to a public (or private) GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **"New app"**, select your repository, branch, and set the main file
   path to `MovieIQ.py`.
4. Streamlit Cloud will automatically install everything listed in
   `requirements.txt` and launch the app.
5. Make sure `movies.csv`, the `assets/` folder, and the `model/` folder are
   all committed to the repo — the app reads them at runtime.

**Note:** if `model/movieiq_rf_model.pkl` isn't present in the repo (e.g., it
was excluded by `.gitignore`), the app will still run but the Model
Performance and Predict Success tabs will show a message asking you to run
`train_analysis.py` first.

## Notes on the Success Rule

A movie is labeled successful when `revenue > budget`. This is a simple
break-even rule and does not account for marketing spend, streaming/licensing
revenue, or non-financial measures of success (critical acclaim, cultural
impact). See `MovieIQ_Written_Answers.docx` for the full discussion of this
choice, along with all other written answers to the project brief.
